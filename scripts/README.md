# 🔧 Utility Scripts

This directory contains utility scripts for the Beach Autonomous Systems project.

## Available Scripts

### setup.sh
Initial project setup script. Clones required repositories and creates directory structure.

**Usage (Linux/WSL):**
```bash
chmod +x scripts/setup.sh
./scripts/setup.sh
```

### Future Scripts
- `build.sh` - Build all ROS 2 packages
- `launch.sh` - Launch the full system
- `test.sh` - Run all tests
- `record.sh` - Record ROS bag files
